# Final submission checklist

Confirm all items against the official day-one instructions.

## Requirements

- [ ] Exact deadline and timezone recorded
- [ ] Required deliverables and file formats recorded
- [ ] Page, word, slide, runtime, or video limits checked
- [ ] Team details and required declarations included
- [ ] Data and external-source usage complies with the rules

## Quality

- [ ] Research question is explicit and answered
- [ ] Key results reproduce from raw data and committed code
- [ ] Figures have readable labels, units, legends, captions, and sources
- [ ] Statistical claims report uncertainty and appropriate validation
- [ ] Assumptions, limitations, bias, and alternative explanations are discussed
- [ ] Every number and citation has been independently checked
- [ ] No secrets, personal data, absolute local paths, or debug output remain

## Delivery

- [ ] Final exports open correctly on another device
- [ ] Filenames follow organiser instructions
- [ ] Submission owner and backup agree on the final version
- [ ] Upload completed before the deadline
- [ ] Confirmation/receipt saved
