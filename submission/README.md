# Submission workspace

Keep editable report, slide, script, or dashboard source files here. Generated PDF, PowerPoint, video, HTML, and ZIP exports are ignored by default; remove the relevant ignore rule if the competition explicitly requires an export to be versioned.

`australia_material_social_report.qmd` is the reproducible Quarto report
source. Rendering it reads the raw OECD file, reruns the audit and core
comparisons, regenerates the report figure, and runs the repository tests.

At kickoff, copy the exact deliverables, filenames, limits, and upload instructions into `CHECKLIST.md`.
